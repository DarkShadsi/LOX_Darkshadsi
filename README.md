# LOX_Darkshadsi

An implementation of the [Lox](https://craftinginterpreters.com/) programming language.

## Overview

This repository contains an implementation of the Lox language as described in Robert Nystrom's *Crafting Interpreters*. Lox is a dynamically typed, object-oriented scripting language.

## Features

- **Data Types:** Numbers, Strings, Booleans, `nil`
- **Expressions:** Arithmetic, comparison, and logical operators
- **Control Flow:** `if` statements, `while` loops, and `for` loops
- **Functions:** First-class functions, closures, and recursion
- **Classes & OOP:** Classes, instances, properties, methods, and inheritance
